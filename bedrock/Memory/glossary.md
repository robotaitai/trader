# Glossary

Project-specific terms, acronyms, and names.

- Investor OS: The portfolio analytics web app built in this repo.
- Local-first: Data is imported, calculated, and persisted in the browser
  without backend services.
- Transaction ledger: A row-based file of buy/sell/dividend/deposit-style
  activity used to derive holdings with average cost.
- Portfolio snapshot: A current-status file or pasted table of holdings with
  active/closed status, current prices, and earnings fields.
- HHI: Herfindahl-Hirschman Index, used here as a portfolio concentration
  score from position weights.
